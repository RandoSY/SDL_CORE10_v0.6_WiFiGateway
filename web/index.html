Application diagnostics are NOT Wi-Fi radio RSSI or physical link-layer packet loss. Lag is estimated from node timestamps + clock-offset pings, with uncertainty approximately RTT/2. A TCP sequence gap indicates missing application samples, not necessarily RF loss.
Web Serial and Web Bluetooth are Chromium-based browser features. Firefox can use Demo, CSV, or WebSocket (when the device provides a compatible endpoint). Serve on localhost/HTTPS for permissioned browser APIs.

One scientific sample, many transports

Adapters include simulation, WebSocket LAN, a live Python WebSocket gateway, USB Web Serial, and BLE Nordic UART Service. A new adapter registers a manifest and emits normalized samples.
